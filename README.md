# East Africa University (EAU) - AI Chatbot Assistant

System-kan waxaa loo dhisay sidii loogu caawin lahaa ardayda iyo booqdayaasha Jaamacadda Bariga Afrika (EAU - Garowe Campus) inay helaan xogta rasmiga ah iyagoo adeegsanaya AI Chatbot Assistant.

---

## 🛠️ Tools & Technologies Used (Sida Buugga ku Qoran)

Mashruucani wuxuu si toos ah u adeegsadaa aaladaha ku qoran buugga qalin-jabinta (**Chapter 3 & Chapter 4**):

* **Frontend:**
  * **HTML5:** Qaab-dhismeedka aasaasiga ah ee websaydka (`index.html`).
  * **CSS3:** Naqshadaynta, midabada, iyo muuqaalka Light/Dark mode (`src/index.css` & Modern CSS/Tailwind).
  * **JavaScript (ES6+ / React):** Dhisidda qeybaha is-dhexgalka (Interactive Components), xakamaynta fariimaha, iyo maaraynta state-ka (`src/App.jsx`, `src/components/*`).
* **Backend:**
  * **Node.js & Express.js:** Server-ka fuliya codsiyada REST API (`server.js`, `/api/chat`, `/api/admin/knowledge`).
* **Artificial Intelligence (AI):**
  * **Google Gemini API:** Moodalka falanqeeya su'aalaha isla markaana soo saara jawaabaha Af-Soomaaliga iyo Af-Ingiriisiga (Bilingual).

---

## 🚀 Sida Loo Kiciyo System-ka (How to Run)

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the System:**
   ```bash
   npm run dev
   ```

3. **Fur Browser-ka:**
   Geli cinwaanka: `http://localhost:3000`
